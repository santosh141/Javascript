# JavaScript Learning Repository

## 📌 Overview
This repository contains JavaScript concepts, examples, programs, exercises, and projects designed for beginners and intermediate learners. It covers fundamental to advanced JavaScript topics with practical examples.

- Data Types
- Operators
- User Input and Output

- if, if-else
- Nested if
- Switch Case
- Loops

  - while loop
  - do-while loop

### Functions
- Function Declaration
- Function Expression
- Arrow Functions
- Parameters and Arguments
- Return Statement

### Arrays
- Creating Arrays
- Array Methods
- Array Iteration
- Multidimensional Arrays

### Objects
- Object Creation
- Properties and Methods
- Object Destructuring
- JSON

### DOM Manipulation
- Selecting Elements
- Event Handling
- DOM Traversal
- Creating and Removing Elements

### ES6 Features
- Template Literals
- Destructuring
- Spread Operator
- Rest Parameters
- Modules

### Asynchronous JavaScript
- Callbacks
- Promises
- Async/Await
- Fetch API

## 🛠 Technologies Used

- HTML5
